# 요구사항 명세서

## 1. 회원 관리

### 1.1 회원가입

**카페 사장**

- 이메일 주소 입력 (필수, 유효성 검증)
- 패스워드 입력 (필수, 8자 이상, 영문+숫자+특수문자 조합)
- 패스워드 확인
- 닉네임 (카페 상호명)
- 회원가입 완료 시 매장 상세 정보 미등록 상태로 가입

**작가**

- 이메일 주소 입력 (필수, 유효성 검증)
- 패스워드 입력 (필수, 8자 이상, 영문+숫자+특수문자 조합)
- 패스워드 확인
- 닉네임 (작가명)
- 회원가입 후 프로필 정보 수정, 피드 형식으로 작품 업로드 가능
- 작품 관심사 선택

**일반 사용자**

- 이메일 주소 입력 (필수, 유효성 검증)
- 패스워드 입력 (필수, 8자 이상, 영문+숫자+특수문자 조합)
- 패스워드 확인
- 닉네임 (필수, 2~15자)
- 나이
- 성별

### 1.2 로그인/로그아웃

- 이메일/패스워드 기반 로그인
- 자동 로그인 옵션
- 패스워드 찾기/재설정 기능
- 로그아웃 기능

## 2. 카페/작품 관리

### 2.1 카페 매장 정보 등록 (카페 사장)

**기본 정보**

- 매장명 (회원가입 정보와 동일)
- 주소 (회원가입 정보와 동일)
- 카페 소개 (최대 500자)
- 연락처
- 영업시간
- 매장 대표 이미지 (최소 3장, 최대 10장)

**매장 특성**

- 인테리어 톤/스타일 (다중 선택: 모던, 빈티지, 미니멀, 내추럴 등)
- 평균 일일 방문객 수

**전시 슬롯 정보**

- 각 벽면별 세부 정보:
    - 벽면 폭(cm) × 높이(cm) (필수)
    - 설치 방식 (레일/훅/기타)
    - 전시 위치 설명
    - AR 공간 스캔 데이터

**전시 조건**

- 전시 가능 기간 (시작일 ~ 종료일)
- 작품 판매 수수료율 (%)
- 추가 요청사항 (텍스트, 최대 500자)

**매장 정보 수정**

- 등록된 매장 정보 수정 가능

### 2.2 작품 등록 (작가) - 피드 형식

**작품 업로드 (인스타그램 스타일)**

- 작품 이미지 (필수, 최소 1장, 최대 10장, 슬라이드 형식)
- 작품명 (필수)
- 작품 설명 (최대 1000자)
- 작품 가격

**작품 기본 정보**

- 카테고리 (필수, 단일 선택: 회화, 사진, 조각, 설치미술, 공예 등)
- 작품 규격 (가로×세로×깊이, cm 단위)
- 재료/기법
- 제작 연도
- 작품 무게 (kg)

**작품 관리**

- 작품 수정 기능
- 작품 삭제 기능

## 3. 카페/작품 탐색

### 3.1 작품 탐색

**필터 옵션**

- 카테고리 (다중 선택)
- 작품 규격 범위 (가로/세로 최소~최대) - 카페 사장만

**정렬 옵션**

- 추천순 (AI 알고리즘 기반 추천, 기본값)
- 최신 등록순
- 인기순 (조회수, 북마크, 평가)

**검색 기능**

- 작품명, 작가명 키워드 검색
- 검색 히스토리 저장

**작품 표시**

- 그리드 뷰 (썸네일)
- 무한 스크롤
- 작가와 작품이 검색 결과에 중복된 경우 작가 목록을 상단에, 작품 목록을 하단에 표시

### 3.2 카페 탐색

**필터 옵션**

- 지역 (시/구/동 단위)
- 전시 슬롯 규격 범위 - 작가만
- 수수료율 범위 - 작가만

**정렬 옵션**

- 추천순 (AI 알고리즘 기반 추천, 기본값)
- 거리순 (가까운순)
- 인기순 (조회수, 북마크, 평가)
- 수수료 낮은순/높은순 - 작가만

**검색 기능**

- 카페명, 지역명 키워드 검색
- 검색 히스토리 저장

**카페 표시**

- 지도에 카페 위치 표시
- 리스트 형태로도 함께 제공

### 3.3 상세 조회 (모든 사용자)

**작품 상세 조회**

- 작품명
- 작품 이미지 (여러 개 슬라이드)
- 작가명, 작가 프로필 이미지
- 작품 가격
- 북마크 수
- 카테고리
- 작품 정보 (크기, 재료, 제작연도)
- 작품 설명
- 작품 상태 표시 (전시 가능/전시 중)
- 전시 장소 정보 (전시 중인 상태일 때만, 카페명, 카페 주소, 전시 기간)

**카페 상세 조회**

- 기본 정보 (매장명, 주소, 소개, 연락처, 영업시간, 이미지)
- 매장 특성 (인테리어 스타일, 일일 방문객 수)
- 전시 슬롯 정보 (규격, 설치 방식, 위치 설명, AR 데이터)
- 전시 조건 (기간, 수수료율, 요청사항)
- 각 슬롯의 현재 상태 표시 (전시 가능/전시 중/전시 예정)
- 전시 중인 작품 정보 (슬롯별)

**작가 프로필 조회**

- 인스타그램 프로필 형식
- 프로필 이미지, 작가명, 소개
- 평가 통계
- 작품 그리드

**카페 프로필 조회**

- 카페 이미지, 카페 상호명, 소개
- 카페 사장 평가 통계
- 과거 전시 이력

### 3.4 인기 콘텐츠 추천

- 조회수, 북마크, 평가 기반 인기 카페/작품 추천

### 3.5 북마크

- 카페 또는 작품 북마크 추가/제거
- 모든 사용자가 카페와 작품 모두 북마크 가능

## 4. 매칭 및 커뮤니케이션

### 4.1 매칭 프로세스

**채팅 시작**

- 작품/카페 상세 페이지에서 채팅 시작 가능
- 카페 사장과 작가 간 1:1 채팅

**채팅을 통한 협의**

- 전시 기간 협의
- 전시 조건 협의 (수수료, 설치 방법 등)
- 전시 슬롯 선택 및 확정

**매칭 동의**

- 채팅 내에서 "매칭 동의" 기능 제공
- 매칭 동의 시 전시 시작일, 종료일, 전시 슬롯 정보 입력
- 양측 모두 동의 시 매칭 자동 완료
- 매칭 완료 알림 발송
- 매칭 완료 시 슬롯 상태가 '전시 예정'으로 변경

**매칭 취소**

- 매칭 완료 후 취소 가능
- 취소 시 슬롯 및 작품 상태가 '전시 가능'으로 복원

### 4.2 전시 일정 관리

**전시 일정 조회**

- 카페 사장: 슬롯별 전시 일정 확인 (어떤 작품이 언제 전시되는지)
- 작가: 작품별 전시 일정 확인 (어느 카페 어느 슬롯에 언제 전시되는지)

**슬롯 상태**

- 전시 가능: 비어있는 슬롯
- 전시 예정: 매칭 완료, 전시 시작 전
- 전시 중: 현재 전시 진행 중

**작품 상태**

- 전시 가능: 전시되지 않은 상태
- 전시 중: 현재 카페에서 전시 중

**상태 자동 전환**

- 전시 시작일이 되면 자동으로 '전시 중' 상태로 변경
- 전시 종료일이 되면 자동으로 '전시 가능' 상태로 변경

### 4.3 인앱 메시징

**메시지 기능**

- 1:1 채팅
- 텍스트 메시지 (최대 1000자)
- 이미지 첨부
- 읽음 확인
- 메시지 알림
- 채팅 내 "매칭 동의" 버튼

**메시지 관리**

- 대화 목록 (최신순/안읽음순 정렬)
- 채팅방 나가기

## 5. 추천 시스템

### 5.1 추천 프로세스

**작품 추천 (카페 사장 대상)**

- 기본 정렬: 추천순 (AI 알고리즘 적용)
- 카페 특성(슬롯 규격, 인테리어 스타일, 과거 전시 이력)에 맞는 작품 우선 노출

**카페 추천 (작가 대상)**

- 기본 정렬: 추천순 (AI 알고리즘 적용)
- 작품 특성(규격, 카테고리, 가격대, 선호 지역)에 맞는 카페 우선 노출

### 5.2 추천 알고리즘

**데이터 수집**

- 사용자 행동 데이터
    - 메시지 발송 이력
    - 북마크
    - 검색 키워드
    - 상세 페이지 체류 시간 및 스크롤 깊이
    - 상세 페이지 조회 이력
- 조회수
- 카테고리

**추천 알고리즘**

- 협업 필터링 (Collaborative Filtering)
    - 유사 사용자 행동 패턴 분석
    - 유사한 카페가 선호한 작품 추천
    - 유사한 작가가 선호한 카페 추천
- 콘텐츠 기반 필터링 (Content-Based Filtering)
    - 작품 특성 매칭 (규격, 카테고리, 가격대)
    - 카페 특성 매칭 (슬롯 규격, 수수료, 위치)
- 하이브리드 추천
    - 가중치 기반 통합 추천
    - 행동 데이터와 콘텐츠 특성 종합 분석

**추천 품질 개선**

- 매칭 성사율 추적
- 사용자 피드백 수집 (매칭 만족도)
- 주기적 알고리즘 재학습

## 6. 평가 관리

### 6.1 전시 종료 후 평가

**상호 평가 시스템**

작가 → 카페 평가

- 평가 선택 (단일 선택)
    - 👍 좋아요
    - 😐 괜찮아요
    - 👎 별로에요
- 간단한 코멘트 작성 (선택, 최대 100자)

카페 사장 → 작가 평가

- 평가 선택 (단일 선택)
    - 👍 좋아요
    - 😐 괜찮아요
    - 👎 별로에요
- 간단한 코멘트 작성 (선택, 최대 100자)

**평가 관리**

- 평가 완료 기한 (전시 종료 후 14일)
- 채팅에 시스템 메시지로 전송
- 평가 수정 불가
- 프로필에 평가 통계 표시 (좋아요/보통/별로 비율)

## 7. 프로필

### 7.1 카페 사장 프로필

**계정 정보 관리**

- 이메일 (수정 불가, 표시만)
- 패스워드 변경
- 프로필 이미지 업로드/변경
- 카페 상호명 수정
- 카페 소개 수정
- 받은 평가 조회
- 회원 탈퇴

**활동 기록**

- 북마크한 카페/작품 리스트

### 7.2 작가 프로필

**프로필 영역**

- 프로필 이미지
- 작가명
- 작가 소개 (최대 250자)
- 받은 평가 통계 (좋아요/보통/별로 비율)

**계정 정보 관리**

- 이메일 (수정 불가, 표시만)
- 패스워드 변경
- 작가명 수정
- 작가 소개 수정
- 프로필 이미지 변경
- 회원 탈퇴

**작품 피드**

- 본인이 업로드한 작품 그리드
- 작품 상세 조회
- 작품 수정/삭제
- 새 작품 업로드 (+ 버튼)

**활동 기록**

- 북마크한 카페/작품 리스트

### 7.3 일반 사용자 프로필

**계정 정보 관리**

- 이메일 (수정 불가, 표시만)
- 패스워드 변경
- 닉네임 수정
- 나이/성별 수정
- 프로필 이미지 업로드/변경
- 회원 탈퇴

**활동 기록**

- 북마크한 카페/작품 리스트
