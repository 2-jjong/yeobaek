# 기획서

## 1. 프로젝트 개요

### 1.1 프로젝트명

여백

### 1.2 프로젝트 소개

여백은 카페의 유휴 벽면/공간과 신진 작가의 작품을 연결하는 양방향 매칭 플랫폼입니다. 카페 사장은 매장의 빈 공간을 활용하여 인테리어를 개선하고, 작가는 작품을 전시하고 판매할 기회를 얻으며, 일반 사용자는 일상 속에서 예술 작품을 감상하고 구매할 수 있는 환경을 제공합니다.

### 1.3 프로젝트 배경 및 필요성

**신진 작가의 어려움**

- 작품 전시 공간 확보의 어려움 (갤러리 대관료 부담, 제한적인 전시 기회)
- 작품 홍보 및 판매 채널 부족
- 일반 대중과의 접점 부족

**카페 운영자의 니즈**

- 차별화된 인테리어 및 브랜딩 요소 필요
- 갤러리 카페 트렌드 증가
- 비용 부담 없는 공간 활용 방안 모색

**일반 소비자의 니즈**

- 미술관/갤러리의 진입 장벽 (시간, 비용, 심리적 부담)
- 일상 속에서 예술 작품을 접하고 싶은 욕구 증가
- 신진 작가 발굴 및 작품 구매 채널 부족

**시장 기회**

- 2024년 기준 전국 카페 수 약 10만 개 이상
- 갤러리 카페, 복합 문화 공간 카페 트렌드 확산
- MZ세대의 '필코노미', '취향 소비' 문화 증가

### 1.4 프로젝트 목표

1. 카페와 작가 간 매칭 프로세스 자동화 및 최적화
2. 사용자 친화적인 모바일 플랫폼 구축
3. 전시 일정 및 평가 관리 시스템 구현
4. 사용자 데이터 기반 추천 알고리즘 도입

### 1.5 기대효과

**작가**

- 작품 인지도 향상
- 전시 기회 확대
- 작품 판매 증가
- 포트폴리오 및 평판 구축

**카페 사장**

- 인테리어 비용 절감
- 브랜딩 강화 및 고객 유입 증가
- 문화 공간으로서의 이미지 제고

**일반 사용자**

- 일상 속 문화 경험 확대
- 신진 작가 발굴 및 작품 구매 기회
- 카페 탐방의 새로운 즐거움

**사회적 효과**

- 예술 생태계 활성화
- 지역 문화 공간 확대
- 카페와 예술의 상생 모델 구축

## 2. 서비스 기획

### 2.1 타겟 사용자

- **작가**: 전시 기회 부족 및 판매 채널 확보의 어려움을 겪는 신진 작가
- **카페 사장**: 인테리어 개선을 통한 고객 유치를 원하는 카페 사장
- **사용자**: 카페 탐방 및 문화 생활 소비를 즐기는 카페 이용객

### 2.2 핵심 기능 정의

**2.2.1 회원 관리**

- **회원가입 및 로그인**: 역할별(작가/카페 사장/일반 사용자) 회원가입, JWT 기반 인증
- **프로필 관리**: 프로필 정보 수정, 패스워드 변경, 회원 탈퇴

**2.2.2 카페/작품 관리**

- **매장 정보 등록 및 공간 스캔**: 기본 정보, 카페 내부 공간 정보, 전시 슬롯, 전시 조건 등록
- **작품 등록**: 피드 형식으로 작품 이미지 및 정보 업로드
- **정보 수정/삭제**: 등록된 카페/작품 정보 수정 및 삭제

**2.2.3 카페/작품 탐색**

- **목록 조회**: 필터링(카테고리, 규격, 지역 등) 및 정렬(추천순, 최신순, 인기순)
- **상세 조회**: 작품/카페 상세 정보 및 전시 상태 확인
- **검색**: 키워드 기반 작품/작가/카페 검색
- **북마크**: 관심 카페/작품 저장
- **지도 뷰**: 카페 위치 마커 및 바텀 시트 리스트

**2.2.4 매칭 및 커뮤니케이션**

- **매칭 요청**: 관심 작품/카페 발견 시 채팅 시작
- **채팅**: 1:1 채팅으로 전시 조건 협의
- **매칭 동의**: 양측 동의 시 전시 일정 확정
- **전시 일정 관리**: 역할별 전시 일정 조회 및 매칭 취소

**2.2.5 평가 관리**

- **전시 평가 작성**: 전시 종료 후 상대방 평가 (좋아요/괜찮아요/별로에요)
- **평가 조회**: 프로필에서 받은 평가 통계 확인

**2.2.6 시스템 기능**

- **추천 알고리즘**: 사용자 행동 데이터 기반 맞춤 작품/카페 추천
- **전시 상태 자동 업데이트**: 날짜 기반 전시 상태 자동 변경
- **행동 데이터 수집**: 북마크, 검색, 조회 등 사용자 활동 수집 및 분석

### 2.3 사용자 시나리오

**시나리오 1: 작가의 카페 매칭**

1. 작가 회원가입 및 프로필 설정
2. 작품 등록 (이미지, 설명, 규격, 가격)
3. 카페 탐색 (지도 뷰, 필터링: 지역/슬롯규격/수수료)
4. 관심 카페 발견 및 상세 정보 확인
5. 카페에 채팅 요청 및 전시 조건 협의
6. 양측 매칭 동의 후 전시 일정 확정
7. 전시 종료 후 카페 평가 작성

**시나리오 2: 카페 사장의 작품 매칭**

1. 카페 사장 회원가입
2. 매장 스캔 및 정보 등록 (슬롯, 전시 조건)
3. 작품 탐색 (필터링: 카테고리/규격, 정렬: 추천순)
4. 관심 작품 발견 및 작가 프로필 확인
5. 작가에게 채팅 요청 및 전시 조건 협의
6. 양측 매칭 동의 후 전시 일정 확정
7. 슬롯별 전시 일정 관리
8. 전시 종료 후 작가 평가 작성

**시나리오 3: 일반 사용자의 작품 감상**

1. 일반 사용자 회원가입
2. 카페 탐색 (지도 뷰, 필터링: 지역/카테고리)
3. 카페 상세 정보 및 전시 작품 확인
4. 관심 작품 북마크 및 작가 프로필 조회
5. 작가의 다른 작품 피드 탐색
6. 작품이 전시된 카페 방문

## 3. 개발 내용

### 3.1 기술 스택

- FE: Android, Jetpack Compose
- BE: Java, Spring Boot
- DB: MySQL
- Infra: Jenkins, Docker

### 3.2 구체화 방안

**3.2.1 AR 기반 카페 공간 스캔**

1. **벽면 스캔 및 측정**
    - Google ARCore의 Depth API를 활용해 카페 벽면을 3D로 스캔
    - 평면 검출(Plane Detection) 기능으로 벽면 영역 자동 인식
    - 실제 벽면 크기(가로×세로) 자동 측정 및 데이터 저장
2. **작품 가상 배치**
    - 작품 이미지를 3D 텍스처로 변환하여 스캔된 벽면에 실시간 렌더링
    - 실제 비율에 맞춰 작품 크기 자동 조정
    - 사용자가 위치, 높이, 각도 조정 가능한 인터랙션 제공
3. **전시 시뮬레이션**
    - 여러 작품을 동시에 배치하여 전시 구성 미리보기
    - 조명 효과 시뮬레이션으로 실제 전시 환경 재현
    - 시뮬레이션 결과를 이미지/영상으로 저장 및 공유

**3.2.2 하이브리드 추천 시스템**

1. **협업 필터링(Collaborative Filtering, CF)**
    - User-based CF: 유사한 취향의 사용자가 선호한 작품/카페 추천
    - Item-based CF: 사용자가 관심 보인 작품/카페와 유사한 항목 추천
    - 사용자 행동 데이터 활용: 북마크, 채팅, 스크롤 깊이, 체류 시간 등
2. **콘텐츠 기반 필터링(Content-Based Filtering, CBF)**
    - 작품 특성: 카테고리, 규격, 가격, 스타일, 작가 이력
    - 카페 특성: 인테리어 스타일, 슬롯 규격, 위치, 방문객 수
    - 코사인 유사도(Cosine Similarity)로 작품-카페 간 매칭 점수 계산
3. **하이브리드 결합**
    - 가중 평균 방식: 최종 점수 = (CF 점수 × 0.?) + (CBF 점수 × 0.?)
    - 콜드 스타트 문제 해결: 신규 사용자/작품/카페는 CBF 우선 적용
    - 데이터 축적 후 CF 가중치 점진적 증가
