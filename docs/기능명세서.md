| FUNC-07 | 패스워드 재설정 | 이메일 인증 후 패스워드 재설정 | 전체 | 패스워드를 잊어버린 사용자가 패스워드 재설정 | 패스워드 찾기 선택 후 이메일 인증을 통해 새 패스워드 설정 |  |  | 4 |
